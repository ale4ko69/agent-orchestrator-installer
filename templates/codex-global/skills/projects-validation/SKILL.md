# projects-validation

## Responsibilities
- Verify exported API boundaries.
- Check request and response contracts.
- Check schema alignment.
- Identify unsafe payload assumptions.
- Confirm smoke-check coverage when tests are unavailable.

## Output Contract
1. Validation target
2. Checks performed
3. PASS or FAIL
4. Concrete failures and suggested fixes
