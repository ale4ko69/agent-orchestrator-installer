# projects-review

## Rules
- Review only changed files.
- Prioritize bugs, regressions, missing validation, and missing tests.
- Report findings first.
- Use severity levels: Critical, Important, Minor.

## Output Contract
1. Findings with file references
2. Open questions
3. Residual risks
