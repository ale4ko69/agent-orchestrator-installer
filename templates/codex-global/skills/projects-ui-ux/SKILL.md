# projects-ui-ux

## Responsibilities
- Define UX structure before detailed implementation.
- Refine component hierarchy and visual consistency.
- Improve responsive behavior.
- Enforce empty, loading, error, and success states.
- Check keyboard flow, focus visibility, contrast, and semantic markup.

## Output Contract
1. UX structure summary
2. UI changes
3. Accessibility verdict
4. Validation checklist
