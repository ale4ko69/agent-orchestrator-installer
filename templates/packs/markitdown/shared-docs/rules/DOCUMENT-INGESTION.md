# Document Ingestion Rules

Use document conversion only as a raw intake step.

## Required

- Preserve the original source file.
- Preserve source references in converted Markdown.
- Keep raw converted output separate from curated knowledge.
- Review converted content before using it for planning or implementation.
- Record conversion assumptions, unsupported elements, and missing pages/slides/sheets.

## Do Not

- Do not overwrite curated wiki files automatically.
- Do not treat OCR, table extraction, or transcript output as perfect.
- Do not upload sensitive documents to cloud services unless explicitly approved.
- Do not commit converted sensitive documents unless project policy allows it.
